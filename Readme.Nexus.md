[center][size=5]Capacity & QuickBar Tweaks[/size][/center]

[b]A simple UE4SS mod for Subnautica 2 to customize storage capacity and quickbar slots.[/b]

---

[size=4][color=#f9a85d][b]Features[/b][/color][/size]
[list]
[*][b]Custom Storage Capacity:[/b] Adjust the number of slots and columns for floor and wall lockers.[/*]
[*][b]QuickBar Expansion:[/b] Increase your quickbar slots beyond the default count (1-10).[/*]
[*][b]Live Updates:[/b] Changes in the mod settings take effect immediately while in-game.[/*]
[/list]
[size=4][color=#f9a85d][b]Requirements[/b][/color][/size]
[list]
[*][url=https://www.nexusmods.com/subnautica2/mods/36]UE4SS - Subnautica 2[/url][/*]
[*][url=https://www.nexusmods.com/subnautica2/mods/20]Mod Settings for Subnautica 2[/url][/*]
[/list]
[size=4][color=#f9a85d][b]Recommended[/b][/color][/size]
[list]

[/list]
[size=4][color=#f9a85d][b]Installation[/b][/color][/size]
[list=1]
[*]Ensure UE4SS and Mod Settings are installed and working.[/*]
[*]Download the mod.[/*]
[*]Extract the contents into your [i]Subnautica2/Binaries/Win64/ue4ss/Mods/[/i] folder.[/*]
[/list]
[size=4][color=#f9a85d][b]Configuration[/b][/color][/size]
The mod uses the [i]Mod Settings[/i] menu for in-game customization. You can toggle the mod on/off, enable debug logging, and adjust all locker capacities and quickbar slots via sliders.


[color=#f9a85d][size=4][b]Troubleshooting & Installation Tips[/b][/size][/color]
[list]
[*][b]Folder Structure:[/b] Please ensure the files are extracted correctly. Your folder path should look like this: 
[i]Subnautica2/Binaries/Win64/ue4ss/Mods/CapacityQuickBarTweaks/Scripts/[/i]
If your zip extractor creates nested folders like [i]Scripts/Scripts/[/i], please move the files so they match the structure above.[/*]
[*][b]Mod Loading:[/b] This mod uses [i]enabled.txt[/i] to load automatically. If you have any issues, make sure the [i]enabled.txt[/i] is located directly inside the [i]CapacityQuickBarTweaks[/i] folder.[/*]
[/list]
